# instructBrain - landing page design mockup

A standalone design mockup of a redesigned instructBrain landing page (instructbrain.com).

This repository is **only** a design mockup. It is deliberately separate from the
`instructbrain` and `instructsite` application repositories and changes nothing in them.

- `index.html` - the whole page. Single self-contained file: inline CSS, no build step,
  no external JavaScript framework.
- Brand visuals are unchanged from the live product: navy surfaces, white `instruct` plus
  Laser Green (`#57ff00`) `Brain` wordmark, Sora / Manrope / Audiowide type.
- Product photography and the 3D icons are referenced directly from
  `https://instructbrain.com/demo/photo-1.jpg` .. `photo-5.jpg` and `https://instructbrain.com/3d/`.
- All numbers, quotes and pricing on the page are the ones already published on the live site.
  Nothing has been invented.

Layout was measured with a headless Chromium at 1440x800, 1280x800 and 1920x1080: no horizontal
scrolling at any of them, and the headline, subhead, both calls to action and the top of the
product visual all sit above the fold at 1440x800.
